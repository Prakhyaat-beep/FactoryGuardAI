# FactoryGuard AI

FactoryGuard AI is an educational industrial machine failure prediction and predictive-maintenance platform. It combines a React/Vite interface, Flask REST API, reproducible scikit-learn pipeline, SQLite storage, rule-based maintenance guidance, alerts, PDF reports, and session authentication.

For complete local setup, architecture, endpoints, and test commands, see [PROJECT_SETUP.md](PROJECT_SETUP.md).
