# FactoryGuard AI: model-comparison experiment

## Research question

Which baseline classifier best identifies machine failures in the AI4I dataset when models receive identical data, preprocessing, and test conditions?

## Dataset

The experiment uses the [UCI AI4I 2020 Predictive Maintenance Dataset](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset). It has 10,000 synthetic-but-industry-representative observations. The binary target is `Machine failure`. The failure rate is 3.39%, so the positive class is imbalanced.

Inputs are air temperature, process temperature, rotational speed, torque, tool wear, and product type. Identifiers and individual failure-mode fields are excluded to avoid leakage.

## Methodology

All models use the same 80/20 stratified train/test split (`random_state=42`) and the same scikit-learn preprocessing pipeline: median imputation plus standard scaling for numeric data, and most-frequent imputation plus one-hot encoding for product type. Class balancing is enabled. The held-out test set contains 2,000 records; the training set contains 8,000.

The compared models are Logistic Regression, Decision Tree, and Random Forest. Training time and inference time are measured with Python's `time.perf_counter` on the local machine, so timings are environment-dependent.

## Selection criterion

The primary model is selected by F1-score for failure class `1`, not accuracy. In predictive maintenance, a high accuracy can hide poor failure identification because failures are rare. Failure-class recall measures missed failures, precision measures false alarms, and F1 balances both.

## Results

Results are generated by `python -m ml.train` and saved in `backend/model/evaluation_results.json`.

| Model | Accuracy | Precision | Recall | F1 | Training time | Inference / record |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Logistic Regression | 82.45% | 14.18% | 82.35% | 24.19% | 0.0213 s | 0.001508 ms |
| Decision Tree | 97.95% | 70.15% | 69.12% | **69.63%** | 0.0239 s | 0.001988 ms |
| Random Forest | 97.90% | 90.62% | 42.65% | 58.00% | 0.3444 s | 0.022910 ms |

The Decision Tree is selected. Its F1 is highest: it identifies substantially more failures than the Random Forest while producing far fewer false alarms than Logistic Regression. The Random Forest has stronger precision, but its lower recall misses more known failures in this test split.

## Limitations

AI4I is synthetic and cannot demonstrate performance on a particular factory. Timings will vary with computer hardware and software versions. This point-in-time binary classifier does not estimate remaining useful life, and the model-derived risk score is not a calibrated operational probability. Real deployment requires validation on representative plant data.
